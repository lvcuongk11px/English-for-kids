# English for Kids V2 — Implementation plan

1. Preserve the V1 application ID, signing configuration, working assets, and data-driven foundation; raise the app version to 2.0.0+2.
2. Replace long fixed questions with configurable Level 1/2/3 prompts and one reusable word-audio file per vocabulary item. Centralize slow learning timing.
3. Introduce a mixed activity engine and registry for Listen & Tap, Picture Matching, Find the Color, Learn & Discover, and Listen & Match.
4. Add the original lightweight Pinky mascot, parent settings, local stars/progress, and a child-friendly Home/Result experience.
5. Expand to 20 complete topics and roughly 300 useful words using licensed Noto Emoji plus original generated cards; regenerate slow offline audio and validate every asset.
6. Run formatting, static analysis, unit/widget tests, asset validation, release builds, APK signature/package checks, and produce the V2 release report.

V1 release APKs remain in `dist/` until V2 passes all gates.
